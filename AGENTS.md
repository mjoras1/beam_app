# Project guidance

This repository is a single-file web app intended for GitHub Pages. Keep the app in the top-level `index.html` so GitHub Pages can serve it directly.

## Project layout

- `AGENTS.md`, `spec.md`, `prompts.md`, and `index.html` belong at the repository root.
- `00_planning/` is for planning notes and sketches.
- `01_data/` is for data files.
- `02_validation/` is for hand calculations and test cases.
- `03_output/` is for screenshots and exported results.

Save every new file in the appropriate location above. Keep the web app itself in the top-level `index.html`; do not add separate app source files.

-After each request, add an entry to `prompts.md` recording what was asked, what changed, and whether it worked.
